# Agent Entry Point

For any website, landing page, marketing site, product site, portfolio, editorial site, or scroll-driven web experience, start with:

- `skills/super-web-dev/SKILL.md`

The master skill routes work to the smallest relevant specialist set.

## Rules

1. Read the master skill before coordinating multiple website disciplines.
2. Do not automatically invoke every specialist.
3. Preserve verified brand constraints and existing product behaviour.
4. Never invent evidence.
5. Do not trade accessibility, mobile usability, or performance for visual novelty.
6. For existing sites, diagnose before redesigning.
7. For implementation work, test behaviour and verify the rendered result.
8. For scroll-driven work, verify multiple scroll positions and reduced-motion behaviour, not just a static screenshot.
