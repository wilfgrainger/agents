## Scroll Craft

Parts of the conceptual model in `scroll-experience-design`, and related improvements across the Super Web Dev pack, were informed by:

- **Project:** `nateherkai/scroll-craft`
- **Author:** Nate Herk
- **Repository:** https://github.com/nateherkai/scroll-craft
- **Licence:** MIT
- **Reviewed revision:** `ea06865c87af61d2e62cb508aebba7e5179753e5` (2026-08-22)

Concepts that influenced this pack include treating scroll as a timeline, separating page structure from visual treatment, deliberately shaping an emotional curve, using one memorable signature interaction, checking new work against prior structural fingerprints, and verifying scroll-driven pages across many rendered states.

This repository does **not** vendor Scroll Craft's JavaScript/CSS engine, KIE asset pipeline, ffmpeg tooling, Playwright harness, templates, or scripts. The specialist skill is an original orchestration/design methodology that can optionally recommend Scroll Craft as one implementation route when appropriate.

The upstream MIT licence remains applicable to any upstream code copied or vendored separately in the future.
